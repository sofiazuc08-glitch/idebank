# Idebank

En employee idea management system bygget med HTML, CSS og JavaScript.

## Filer

- **tom.html** - Login-side
- **sofia.html** - Opret ny idé
- **index.html** - Dashboard for medarbejdere
- **empty.html** - Admin-panel for leder

## Login

### Normal bruger
- Brugernavn: Hvad som helst
- Adgangskode: Hvad som helst
- Sendes til: index.html (eget dashboard)

### Admin (Tommyleder)
- Brugernavn: `tommyleder`
- Adgangskode: `sofiamichelle`
- Sendes til: empty.html (admin panel)

## Funktionalitet

✅ Login-system med roller
✅ Opret idéer
✅ Se dine idéer på dashboard
✅ Admin kan se alle idéer
✅ LocalStorage til datapersistens

## Hvordan bruger du det?

1. Åbn `tom.html` i en browser
2. Log ind med dine oplysninger
3. Opret idéer, se dine idéer, eller administrer som leder
